# مجلد الصور

ضع صور الاحتفال هنا مرقّمة من ١ فصاعدًا — والامتداد لا يهم:

```
photos/1.jpeg   ✅ موجودة
photos/2.jpeg   ✅ موجودة
photos/3.jpeg   ✅ موجودة
photos/4.jpeg   ✅ موجودة
photos/5.jpg    ← أضِف صورة خامسة بهذا الاسم وستظهر تلقائيًا
```

الصفحة تجرّب `jpg` و`jpeg` و`png` و`webp` لكل رقم وتأخذ أول امتداد موجود،
وتتوقّف عن البحث بعد رقمين متتاليين غير موجودين حتى لا تُثقل بيانات الضيف.

**أي صورة غير موجودة تُتجاهل تلقائيًا**، وإذا لم توجد أي صورة يختفي قسم
«من ليالينا» بالكامل ولا يظهر أي فراغ للضيوف.

## أسماء بحروف عربية

الصور ذات الأسماء العربية أو التي بها مسافات تُضاف إلى قائمة `extraPhotos`
في أعلى `assets/app.js` وتُرمَّز تلقائيًا — مثل `كامبو والعريس.jpeg` الموجودة الآن.
وتظهر دائمًا بعد الصور المرقّمة.

## نصائح

- أفضل مقاس: عمودي (بنسبة ٣:٤ تقريبًا) بعرض ١٢٠٠ بكسل، وحجم أقل من ٥٠٠ كيلوبايت
  لكل صورة حتى تفتح الدعوة بسرعة على بيانات الموبايل.
- الترتيب على الصفحة هو ترتيب الأرقام، فأعِد التسمية لتغيير الترتيب.
