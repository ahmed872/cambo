# مجلد الصور

ضع صور الاحتفال هنا بهذه الأسماء بالضبط:

```
photos/01.jpg
photos/02.jpg
photos/03.jpg
photos/04.jpg
photos/05.jpg
photos/06.jpg
```

- الصفحة تفحص كل صورة قبل عرضها: **أي صورة غير موجودة تُتجاهل تلقائيًا**،
  وإذا لم توجد أي صورة يختفي قسم «من ليالينا» بالكامل ولا يظهر أي فراغ للضيوف.
- أفضل مقاس: عمودي (بنسبة ٣:٤ تقريبًا) بعرض ١٢٠٠ بكسل، وحجم أقل من ٥٠٠ كيلوبايت
  لكل صورة حتى تفتح الدعوة بسرعة على بيانات الموبايل.
- لإضافة أو حذف صور، عدّل قائمة `photos` في أعلى ملف `assets/app.js`.
