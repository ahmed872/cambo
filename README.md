## ما الذي تتضمنه الدعوة

- **غلاف بفتح تفاعلي** — قوس ذهبي يُرسم أمام الضيف ثم زر «افتح الدعوة».
- **آية الروم ٢١** بخط أميري، نفس العبارة المكتوبة على خلفية الحفل.
- **عدّاد تنازلي حي** للأيام والساعات والدقائق والثواني بالأرقام العربية.
- **كلمة الدعوة** بلهجة مصرية دافئة من صاحب لصاحبه، موقّعة باسم كابو.
- **بطاقات التفاصيل**: الموعد، المكان، برنامج الليلة.
- **إضافة إلى التقويم**: زر لتقويم Google وآخر لتنزيل ملف `.ics` (بتنبيه قبل ٣ ساعات).
- **خريطة تفاعلية** + زر «ابدأ التوجيه» يفتح المسار من مكان الضيف حتى القاعة.
- **ألبوم صور** بعارض ملء الشاشة، يكتشف الصور تلقائيًا (انظر `photos/README.md`).
- **تأكيد الحضور عبر واتساب** وزر مشاركة يستخدم مشاركة النظام على الموبايل.
- **بتلات متساقطة** برسم على Canvas، تحترم إعداد `prefers-reduced-motion`.
- **لوحة ترحيب** من صورتَي العريس والعروسة وهما صغيران، مفصولتان عن خلفيتيهما
  ومدموجتان في صورة واحدة بخط Playfair وGreat Vibes وAmiri.
- **توقيع ويديفاي** في آخر الصفحة بروابط البورتفوليو والانستجرام.
- تصميم عربي كامل RTL، متجاوب مع كل المقاسات، ويعمل بدون أي مكتبات خارجية.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

> ملاحظة: الخريطة والخطوط تحتاج اتصالًا بالإنترنت.

## النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch**،
واختر الفرع ثم المجلد `/ (root)`. سيصبح الرابط جاهزًا للإرسال على واتساب.

## التخصيص

كل ما قد تحتاج تغييره موجود في كائن `CONFIG` في أعلى `assets/app.js`:

```js
const CONFIG = {
  groom: 'حسام',
  bride: 'حنان',
  host:  'كابو',
  startISO: '2026-08-06T20:00:00+03:00',   // موعد الحفل
  hours: 5,                                 // مدة الحفل للتقويم
  venue: 'قاعة جردينيا',
  venueArea: 'دمرو — مركز المحلة الكبرى، محافظة الغربية',
  mapLink: 'https://maps.app.goo.gl/ZZeN1Cjo58YaEwGKA',  // زر «افتح موقع الفرح»
  coords:  '',                              // الخريطة المدمجة والتوجيه (اتركها فارغة = بحث بالاسم)
  mapQuery: '…',                            // بحث احتياطي بالاسم
  whatsapp: '201091779085',                 // رقم كابو لتأكيد الحضور
  photoCount: 12,                           // أقصى عدد صور مرقّمة يبحث عنها
  photoExts: ['jpg','jpeg','png','webp'],
  extraPhotos: ['كامبو والعريس.jpeg']       // أسماء عربية أو بها مسافات
};
```

- **رقم تأكيد الحضور**: ضع رقم كابو أو العريس في `whatsapp` بالصيغة الدولية بدون `+`.
  إن تُرك فارغًا يفتح واتساب ليختار الضيف المرسل إليه بنفسه.
- **الخريطة**: `mapLink` يفتح المكان بدبوسه المضبوط في تطبيق الخرائط، و`coords`
  تُشغّل الخريطة المدمجة وزر التوجيه على نفس النقطة. لو غيّرت المكان، خذ
  الإحداثيات من رابط خرائط Google بعد علامة `@`.
- **معاينة واتساب**: بعد النشر، اجعل `og:image` في `index.html` رابطًا مطلقًا
  (مثل `https://<user>.github.io/cambo/assets/img/welcome-board.jpg`) لتظهر
  لوحة الترحيب في معاينة الرابط.
- **الألوان**: متغيّرات CSS في أعلى `assets/styles.css` (`--gold`, `--emerald`, `--ivory`).
- **توقيع ويديفاي**: كتلة `<div class="brand">` في آخر `index.html` — غيّر فيها
  الروابط أو النص عند إعادة استخدام القالب لعميل آخر.
